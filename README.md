# AMCO FACTORY Portal

Static website. No build required.

Upload these extracted files to the repository root. Keep index.html, pages/, assets/, images/ and .nojekyll together.

GitHub Pages: Settings > Pages > Deploy from a branch > main > / (root) > Save.

Supabase migrations are managed separately in the original local project and are not executed by GitHub Pages.

This release has passed offline syntax, reference and security-helper tests. Live authentication, database policies and PDF output still require deployment testing.
